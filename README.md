**Promptomat Logo Design System**

The Promptomat app logo, specified: construction and geometry, lockups, size floor,
colour behaviour, and the mark in use — browser chrome, navigation bar, and the sign in
and sign up screens.

Live: https://blackpossum.github.io/Promptomat-logo/

- `index.html` — the board
- `css/main.css` — its styles

Static HTML and CSS, no build step. Deployed from `main` by
`.github/workflows/static.yml`, which uploads the repository as-is.
